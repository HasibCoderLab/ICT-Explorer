A responsive, frontend-only ICT practical assignment made with HTML, CSS and Vanilla JavaScript. The visual system follows the supplied school crest: deep green and white as the main colours, with restrained red and gold accents. The design is intentionally academic and clean, with no decorative gradients or heavy animations.

## Run locally
1. Extract the ZIP file.
2. Open the `ICT-Explorer` folder in VS Code.
3. Open `index.html` in a browser, or use Live Server.

## Project sections and practical features
- Assignment cover with school logo and student information
- Meaning and basic components of ICT
- Input–Process–Output–Storage message demonstration
- Six real-world ICT application areas
- Three interactive learning experiments
- Digital safety / suspicious-message activity
- Interactive ICT development timeline
- Ten-question quiz with explanations and score
- Feedback form with a browser-based result chart
- Responsive layout and light/dark display option

## Important notes
- Feedback is stored only in the current browser using LocalStorage. It is not sent to a server.
- Lucide icons and Google Fonts use external CDNs; an internet connection is needed for those assets.
- Review the assignment content and any dates with your textbook or teacher before submission.
